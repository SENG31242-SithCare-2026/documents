# SithCare Documents Repository

## Purpose
This repository serves as the central host for all project artefacts and documentation for the SithCare system. SithCare is a mental health support web application designed to make mental healthcare more accessible, private, and user-friendly. This project is being developed for the SENG 31242 System Design Project by Group 10.

## Contents Structure
This repository contains the following mandatory directories and files:

* **`/srs`**: Software Requirements Specification documents in both PDF and Markdown source formats.
* **`/sds`**: Software Design Specification documents in both PDF and source formats.
* **`/pitch`**: The Idea Pitch deck as a PDF (maximum 10 slides) and the signed Project Approval Form.
* **`/planning`**: Project Timeline (Gantt chart) in PNG or PDF format.
* **`/architecture/decisions`**: Architectural Decision Records (ADRs) saved as Markdown files.
* **`/meeting-notes`**: Meeting notes and log forms saved as Markdown files.
* **`/presentation`**: The final Design Presentation deck in PDF format.
* **`/diagrams`**: Source files for all UML and system diagrams (e.g., `.drawio`, `.puml`) must be committed alongside their exported SVG or high-resolution PNG versions. 

## Required Tooling
To effectively view, edit, and review the contents of this repository, the following tools are required:
* **Markdown Editor**: To view and edit `.md` documentation files.
* **Diagramming Software**: draw.io/diagrams.net (for `.drawio` files) or PlantUML (for `.puml` files).
* **PDF Viewer**: To review final exported documents and pitch decks.
