# 📝 Meeting Notes

This folder contains all the weekly stand-up and project meeting notes for the team. 

## 📌 File Naming Convention
To keep our notes strictly organized by date, you **must** use the following format when creating a new file:
`YYYY-MM-DD-Topic.md`

**Examples:**
* `2026-05-09-Week-2-Standup.md`
* `2026-05-16-Sprint-1-Planning.md`

---
